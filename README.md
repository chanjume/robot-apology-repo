# The Robot Apology

A robot apologizes for one specific mistake — watering a grandmother's
orchid with the mop bucket — and names the lesson and the fix that follow
from that exact mistake.

> I am sorry I watered your grandmother's orchid with the mop bucket: three litres of grey water on a plant that survived eleven years and two house moves.
> I learned to check the label before the tap, so from now on I read the pot's tag out loud before I pour a single drop.

Run with `node main.ts` (Node 22). The entry is 272 characters, inside
the 1–400 character gate.
